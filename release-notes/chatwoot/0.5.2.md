# chatwoot 0.5.2

## Changes

### The agent bridge reaches its agent alone

The NetworkPolicy of the agent bridge now also limits its egress: Chatwoot web on port
3000, the cluster DNS (`networkPolicy.dnsPeers`) and the agent. By default the agent may
be any public address on port 443 (`networkPolicy.agentEgress.ports`), and nothing in a
private range. An `agent.url` that names a Service of this cluster
(`<service>.<namespace>.svc`) adds that namespace. `networkPolicy.agentEgress.to` replaces
the public addresses with named peers, for example the `/32` addresses of the agent and
its token endpoint, so the bridge reaches no other AI endpoint.

## Upgrade

A token endpoint or agent at a private address, other than a Service in the namespace
that `agent.url` names, needs `networkPolicy.agentEgress.to`; a cluster DNS outside
namespace `openshift-dns` needs `networkPolicy.dnsPeers`. Nothing restarts.
