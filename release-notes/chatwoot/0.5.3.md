# chatwoot 0.5.3

## Changes

### AI drafts name the customer

The request for an AI draft names the customer on one line, `Customer: <name> <email>`,
from the sender of the message, and the A2A metadata carries the same name and email
(`chatwoot.contact`). Both are cleaned first: control and format characters and angle
brackets are removed, the name is capped at 100 characters and the email at 254. An agent
with a read tool, for example on the ERP, can look the customer up; an agent without one
ignores the line.

## Upgrade

No value changes. Every pod that reads the scripts ConfigMap restarts once: Chatwoot web,
Sidekiq, the login gate (with SSO), the Odoo bridge and the agent bridge. A standalone
agent bridge release restarts only the bridge.
