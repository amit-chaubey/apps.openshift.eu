# chatwoot 0.5.3

## Changes

### AI drafts name the customer

The request for an AI draft names the customer on one line, `Customer: <name> <email>`,
from the sender of the message, and the A2A metadata carries the same name and email
(`chatwoot.contact`). An agent with a read tool, for example on the ERP, can look the
customer up; an agent without one ignores the line.

## Upgrade

No value changes. The agent bridge restarts once for the new script.
