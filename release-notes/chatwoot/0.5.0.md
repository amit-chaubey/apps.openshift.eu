# chatwoot 0.5.0

## Changes

### AI drafts as private notes

`draftAgent.enabled` lets the A2A agent of `agent.url` draft the next reply to every
customer message in `draftAgent.inboxes`. The draft lands in the conversation as a private
note for staff to check, edit and send; the draft path refuses to write anything that is
not a private note. The prepare Job keeps the drafts' author (an agent under `.invalid`,
member of the listed inboxes) and a signed account webhook of new messages to the bridge.

### Client secret for the agent

`agent.auth.type: clientSecret` gets the agent's access token with a client credentials
grant and the client secret of Secret `chatwoot-agent-client`, for OAuth servers that
cannot tell this cluster's ServiceAccount tokens from another cluster's with the same
issuer.

## Upgrade

Nothing to do. With `secrets.type: externalSecret`, `draftAgent.enabled` needs the vault
items `chatwoot-draft-token` and `chatwoot-draft-webhook` (or other names under
`secrets.externalSecret.items`), and `clientSecret` the item `chatwoot-agent-client-secret`.
