# chatwoot 0.5.1

## Fixes

### AI drafts reach the bridge

With `draftAgent.enabled` and `agentBot.enabled` off, Chatwoot refused the draft webhook
to `http://chatwoot-agent-bridge:8080/draft` ("has no public ip addresses"), and no draft
ever appeared. The bridge address that may receive a webhook on a private address is now
also set for `draftAgent.enabled`.
