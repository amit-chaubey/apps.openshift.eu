# qdrant 0.3.0

Released 2026-10-21.

## Changes

### Let qdrant memory pick its model ([#22](https://github.com/hoolia/apps.openshift.eu/pull/22))

qdrant 0.3.0 runs the image of upstream's own Dockerfile, which
downloads the embedding model at first use: the model now goes to a
volume once, so later starts need no internet, and a random UID gets
writable cache and home directories there. mcp.embeddingModel selects
the FastEmbed model, for example the multilingual MiniLM for teams
that write in more than one language.
