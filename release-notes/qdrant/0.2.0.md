# qdrant 0.2.0

Released 2026-10-21.

## Changes

### Add memory tools to chart qdrant ([#21](https://github.com/hoolia/apps.openshift.eu/pull/21))

qdrant 0.2.0 runs the official mcp-server-qdrant next to Qdrant when
mcp.image is set: qdrant-find and qdrant-store on streamable HTTP,
on a Service an MCP gateway discovers by its appProtocol. Installing
the chart gives a project's agents a shared long-term memory and
removing it takes the tools away, with nothing to change on the agents.

The tool descriptions carry the usage rules (search at the start of a
task, save decisions, preferences and lessons), because that is the
only guidance that exists exactly when the tools do. The server can
reach its own Qdrant and DNS only.
