# qdrant 0.3.1

Released 2026-10-21.

## Changes

### Give qdrant memory tools time to start ([#23](https://github.com/hoolia/apps.openshift.eu/pull/23))

Loading the embedding model takes about 90 seconds on one CPU even
from the cache, so the liveness probe killed the server before it
listened. A startup probe now allows ten minutes, which also covers
the first model download.
