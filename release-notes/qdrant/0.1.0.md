# qdrant 0.1.0

Released 2026-10-21.

## Changes

### Add chart qdrant ([#20](https://github.com/hoolia/apps.openshift.eu/pull/20))

One Qdrant vector database per release namespace, for RAG and agent
memory. Based on the chart Amit Choubey wrote for chat.grn.cloud,
moved here from openshift-config so tenants install it from the
marketplace.

The API key is generated once and kept on upgrade, or read from a
secret store; the health endpoints need no key.
