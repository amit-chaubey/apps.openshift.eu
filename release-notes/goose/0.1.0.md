# goose 0.1.0

Released 2026-11-16.

## Changes

### First release

goose 1.59.2 with a browser terminal (`goose session` in ttyd) behind the OpenShift login,
`goose serve` on its own Route for goose Desktop, a token proxy to the model gateway, and
an A2A bridge that runs each A2A message as a goose turn over ACP, one goose session per
A2A `contextId`. With kagent installed, the chart registers a BYO kagent Agent.

## Upgrade

New chart; nothing to upgrade.
