# mcp-officeagent 0.1.1

Released 2026-10-26.

## Changes

### Annotations on the documents claim

`documents.persistence.annotations` adds annotations to the chart's
PersistentVolumeClaim, for example
`argocd.argoproj.io/sync-options: Delete=false,Prune=false` to keep the
documents when Argo CD deletes the Application. The default adds none.
