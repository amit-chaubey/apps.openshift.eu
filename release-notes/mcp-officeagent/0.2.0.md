# mcp-officeagent 0.2.0

Released 2026-10-27.

## Changes

### Optional token check in front of the server

`auth.enabled` adds an Envoy sidecar that checks a bearer JWT on every
request but `/healthz`: signed by `auth.issuerUrl`, for one of
`auth.audiences` and, when set, a member of one of `auth.allowedGroups`.
The Service port then reaches the sidecar and the server listens on
localhost only, so the server can be exposed beyond an MCP gateway, for
example through a Route that a gateway passes the caller's token to.
Without `auth.issuerUrl` the check refuses every request but `/healthz`.
An entry of `auth.audiences` is a template, so a parent chart can derive
it, for example from `{{ .Release.Namespace }}`.
The default stays off: an installation without the new values renders the
same objects as 0.1.1.

## Upgrade

Nothing to do. To switch the check on, set `auth.enabled`,
`auth.issuerUrl` and `auth.audiences`.
