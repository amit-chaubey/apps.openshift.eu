# mcp-officeagent 0.1.0

Released 2026-10-26.

## Changes

### New chart: the Office documents MCP server for a project's agents

Runs ilia-sokolov OfficeAgent.NET 1.2.0 from its upstream image. Agents create, read
and edit Word, PowerPoint and Excel files headless: text and styles, tables, images,
shapes, charts, slides, comments and Word tracked changes. The server serves streamable
HTTP at `/` behind an MCP gateway and admits only the own project and the namespaces you
list.

### Two connections

`session` holds documents an agent imports, in memory; `documents` keeps files on a
PersistentVolumeClaim across restarts. Neither needs a secret.
