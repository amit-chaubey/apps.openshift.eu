# nextcloud 0.7.0

Released 2026-10-25.

## Changes

### Login with OpenID Connect

The chart sets up the app user_oidc once oidc.discoveryUri and
oidc.clientId are given (oidc.enabled is true by default). Users log in
with the provider, local logins keep working, and groups from the
groups claim are created and kept in step. oidc.groupsRegex limits the
login to users with a matching group; a group admin in the claim makes
the user an administrator. With oidc.bearer, API and WebDAV calls with
a Bearer token of the provider are accepted and create the user on the
first call, which lets agents use Nextcloud with their own token.

The client secret is secrets.oidcClientSecret, or the vault item
nextcloud-oidc-client with secrets.type externalSecret.

## Upgrade

Nothing changes until oidc.discoveryUri and oidc.clientId are set.
