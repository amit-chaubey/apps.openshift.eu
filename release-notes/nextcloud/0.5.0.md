# nextcloud 0.5.0

Released 2026-10-24.

## Changes

### nextcloud 0.5.0 generates passwords with ESO ([#39](https://github.com/hoolia/apps.openshift.eu/pull/39))

With secrets.generator.enabled the External Secrets Operator owns the
Secret nextcloud-credentials and generates each empty administrator and
database password once (Password generator, refreshPolicy CreatedOnce,
immutable target). Argo CD renders without cluster access, so the
lookup-based generation could not keep a password there; a caller no
longer has to pass the passwords as values.

Labels and annotations of the generated Secret are a value, so a
platform can mark it, for example to copy the login to a vault.
The default stays off and renders the same objects as 0.4.11.
