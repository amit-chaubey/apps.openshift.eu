# nextcloud 0.11.0

Released 2026-10-27.

## Changes

### Token check in front of the Office documents MCP server

The chart installs `mcp-officeagent` 0.2.0 with its token check on: every call
to the `officeagent` MCP server but `/healthz` needs a bearer token of
`mcp-officeagent.auth.issuerUrl` issued for this instance (audience: the
release namespace, the name of the instance's OpenID Connect client). The
server can then be exposed beyond the project, for example through a Route
that an MCP gateway passes the caller's token to.

`mcp-officeagent.auth.issuerUrl` has no default. Until it is set the
`officeagent` server refuses every call; Nextcloud, OnlyOffice and the live
editing server are not affected.

## Upgrade

To keep using the `officeagent` server, set `mcp-officeagent.auth.issuerUrl`
to the issuer of your callers' tokens. If the instance's OpenID Connect client
is not named after the project, also set `mcp-officeagent.auth.audiences` to
its client id. To keep the server without a token check, set
`mcp-officeagent.auth.enabled: false`.
