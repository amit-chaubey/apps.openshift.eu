# nextcloud 0.8.1

Released 2026-10-26.

## Changes

### Data volumes survive deleting the Application

The chart's data volumes (`nextcloud-nextcloud` for the installation,
`nextcloud-nextcloud-data` for user files and `mailu-storage` for mail)
carried only `helm.sh/resource-policy: keep`, which Argo CD ignores. A
cascading delete of the Application, which is how a cancelled order is
removed, deleted the customer's files and mail with it. The three
volumes now carry `argocd.argoproj.io/sync-options: Delete=false,Prune=false`,
so Argo CD leaves them in place when the Application is deleted or a
volume leaves the rendered manifests.

Everything else is identical to 0.8.0 (Nextcloud 34.0.5).

## Upgrade

Only annotations on existing volumes change; nothing restarts. An
instance on Nextcloud 33 can take this release instead of 0.8.0.
