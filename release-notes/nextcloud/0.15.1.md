# nextcloud 0.15.1

## Changes

### Office MCP servers only with OnlyOffice

`mcp-officeagent` and `mcp-onlyoffice-live` run only with `onlyoffice.enabled`. With
OnlyOffice off, neither server, its Route below `/mcp/` nor the ConfigMap
`nextcloud-public-url` is rendered, whatever `mcp-officeagent.enabled` and
`mcp-onlyoffice-live.enabled` say. With OnlyOffice on, those two values still switch each
server off. `mcp-nextcloud` does not depend on OnlyOffice and is unchanged.

## Upgrade

- With `onlyoffice.enabled: false`, an upgrade from 0.15.0 removes the Deployments, Services,
  NetworkPolicies and Routes of `officeagent` and `office-live`. The claim
  `officeagent-documents` stays (`helm.sh/resource-policy: keep`); delete it by hand when
  its documents are not needed.
- Nextcloud restarts once (pod annotation `chart-version`).
