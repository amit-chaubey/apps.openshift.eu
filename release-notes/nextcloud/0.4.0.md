# nextcloud 0.4.0

Released 2026-10-05.

## Changes

### Add AI, OnlyOffice setup and public TURN to nextcloud

Version 0.4.0 connects OnlyOffice by itself, adds the AI integration
against an OpenAI-compatible endpoint, lets the TURN server take a
public address from a load balancer and advertise it by resolving its
own name, and opens that port in the project's network policy.

The setup script now sets the whiteboard secret in the form the app
accepts, Apache sends the HSTS header, and the maintenance window and
mimetype repair are applied, so the setup checks pass. Secrets are no
longer written to the pod log.
