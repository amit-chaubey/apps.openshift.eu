# nextcloud 0.15.0

## Changes

### Every component on one host

OnlyOffice, Talk signaling and recording, whiteboard, push and the MCP servers answer below
paths of `route.hostname`: `/office`, `/talk/signaling`, `/talk/recording`, `/whiteboard`,
`/push`, `/mcp/...`. A tenant needs one DNS name and one certificate. The Routes are named
after their paths.

### Mailu below /mail

With `mailu.enabled`, the Mailu admin is served at `/mail/admin/` and webmail at
`/mail/inbox/`, through the Mailu front (`mailRoute.enabled`, default `true`). With
`externalSites` (default `true`) both appear in the Nextcloud menu; the mail admin entry
only for group `admin`. The menu is written only while the External sites app has no sites,
so an edited menu is kept.

### Nextcloud admins are Mailu admins

The mail cron gives every mailbox the chart created for a member of Nextcloud group `admin`
the Mailu admin role, and takes it away when the user leaves the group. An address outside
`mail.domains` (a public provider) never gets a mailbox. A mail domain added later is picked
up by users that were skipped before.

## Upgrade

- The values `onlyoffice.host` and `talk.signaling.host` are gone. The hostnames
  `office-<host>` and `signaling-<host>` are no longer used: their Routes are removed and
  their DNS records can go.
- Nextcloud restarts once (pod annotation `chart-version`); the Mailu front restarts once
  for its new volume `mail-prefix`.
