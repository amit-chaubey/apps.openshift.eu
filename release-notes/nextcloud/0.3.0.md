# nextcloud 0.3.0

Released 2026-10-05.

## Changes

### Add Talk, push, whiteboard, monitoring and backup to nextcloud

Version 0.3.0 carries the rest of what the platform's own Nextcloud
runs: Redis, notify-push and the whiteboard (on by default), Talk with
signaling, TURN and recording, the task worker, exporters with alert
rules, and a scheduled database backup to a bucket claim (off by
default). Every secret is generated once; nothing asks for a public
address unless the TURN Service is set to LoadBalancer.
