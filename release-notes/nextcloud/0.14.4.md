# nextcloud 0.14.4

## Changes

### A chart upgrade applies its setup

Nextcloud carries the pod annotation `chart-version`, so every upgrade of
this chart restarts Nextcloud and its start-up setup runs again. Before, an upgrade that
only changed the setup script (for example 0.14.2, which sets `overwrite.cli.url`) left
Nextcloud running with the old settings until something else restarted it. A render fails
when the annotation and the chart version differ.

## Upgrade

No values change. Nextcloud restarts once, and again at every later chart upgrade.
