# nextcloud 0.19.1

Released 2026-11-15.

## Changes

### Refused mail domains

New value `mail.refusedDomainPattern`: a regular expression (RE2, case-insensitive). When
the mail server is on and `mailu.upstream.domain` matches it, the render stops with the
message "mail domain ... is not allowed here: give a domain you own, or set mailu.enabled
false to run without mail". An installation uses it to keep its own zones out of customer
mail domains. Example: `(^|\.)example\.net$` refuses `example.net` and every name below it.

The default is empty: every domain is accepted, as in 0.19.0.

## Upgrade

No action. The chart renders the same objects as 0.19.0 apart from the `chart-version` pod
annotations, so the Nextcloud and Mailu front pods restart once.
