# nextcloud 0.8.0

Released 2026-10-25.

## Changes

### Nextcloud 34.0.5

The chart runs Nextcloud 34.0.5 (image `34.0.5-apache`, pinned by digest).
Nextcloud upgrades one major version at a time: this release moves
instances from 33 to 34, and the next major (35) follows in a later
chart release.

### Store apps are updated after an upgrade

A major upgrade disables store apps that have no release for the new
version. With settings.repairOnUpgrade (on by default), the setup step
that runs once per Nextcloud version now updates all store apps first,
so OnlyOffice, Talk, the whiteboard, user_oidc and the other apps the
chart enables come back on their compatible release.

## Upgrade

The first start after the upgrade runs the database migration
(`occ upgrade`) with Nextcloud in maintenance mode; it takes a few
minutes on a small instance. Take a backup first. An instance on
Nextcloud 33 must take this release before 0.9.0.
