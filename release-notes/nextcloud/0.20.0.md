# nextcloud 0.20.0

Released 2026-11-17.

## Changes

### Silent login with a running provider session

New value `oidc.silentLogin`, on by default. A browser that opens the login page first asks
the single sign-on provider without a prompt (`prompt=none`):

- With a session at the provider, the user is logged in without a click.
- Without one, the provider answers `login_required` and the login page shows as before,
  with the local login form and the login button.
- The login button stays a normal login and shows the provider's login page.

A cookie `nc_sso_tried` limits the attempt to once per 5 minutes per browser, so the login
page never loops. `/login?direct=1`, POST requests and requests that are not a browser
page load (WebDAV, OCS, the desktop and mobile clients) are left alone.

A PHP `auto_prepend_file` (`/opt/nextcloud-chart/silent-login.php`) carries the behaviour;
it does nothing with `oidc.silentLogin: false` or without a provider. The setup writes the
provider's id to `config/.chart-sso-provider`, which the web server does not serve.

## Upgrade

No action. The Nextcloud and Mailu front pods restart once for the `chart-version` pod
annotations; the Nextcloud pod needs that restart for the new PHP setting. Within a minute
of the start the cron sidecar writes the provider id, and silent login works from then on.
To keep the old behaviour, set `oidc.silentLogin: false`.
