# nextcloud 0.14.1

Released 2026-10-27.

## Changes

### A mailbox has the user's own email address

A new user's mailbox on the mail server now has the email address the user has in
Nextcloud, for an OpenID Connect user the login email, instead of
`<user id>@<mail domain>`. The Mail app account uses that address as email and IMAP
user.

Only addresses in the mail domains get a mailbox. `mail.domains` lists them; empty
(default) means `mailu.upstream.domain`. The setup adds each of them to the mail server.
A user without an email address, or with an address in another domain, gets no mailbox
and one log line in the container `nextcloud-cron`; the user is tried again when the
address changes. Never list a public mail provider such as `gmail.com`: the mail server
treats every domain it hosts as local, so mail to that provider would no longer leave.

## Upgrade

Nothing to do. Mailboxes `<user id>@<mail domain>` made by 0.14.0 and their Mail
accounts stay as they are; they are not changed or deleted. Users who got no mailbox yet
get one with their email address. List further domains you own in `mail.domains` and
give them the same DNS records as the mail domain.
