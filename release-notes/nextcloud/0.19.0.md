# nextcloud 0.19.0

Released 2026-11-15.

## Changes

### Mail off without a mail domain

The chart refers to the mail server only when `mailu.enabled` is `true` and
`mailu.upstream.domain` is set (helper `wrapper.mailuActive`): the mail Route, the
webmail login, the Mail app setup, the external site Webmail and the chart-version check
of the Mailu front.

The Mailu subchart itself follows `mailu.enabled` only, because a Helm condition reads a
boolean. `mailu.enabled` `true` with an empty `mailu.upstream.domain` now stops the render
with the message "mailu.enabled is true but mailu.upstream.domain is empty" instead of the
upstream Mailu error. To run without mail, set `mailu.enabled` `false`; the domain may
then stay empty.

## Upgrade

No action. With a mail domain set, the chart renders the same objects as 0.18.0 apart from
the `chart-version` pod annotations, so the Nextcloud and Mailu front pods restart once.

Setting `mailu.enabled` `false` on a running install deletes the mail server and its
volume `mailu-storage` with every mailbox. Back up the mail first.
