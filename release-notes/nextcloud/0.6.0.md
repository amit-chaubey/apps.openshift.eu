# nextcloud 0.6.0

Released 2026-10-24.

## Changes

### nextcloud 0.6.0 splits the credentials Secret ([#40](https://github.com/hoolia/apps.openshift.eu/pull/40))

nextcloud-credentials held the administrator, the database user, the
database root password and an SMTP host nobody read. It is now three
Secrets with the keys username and password: nextcloud-admin,
nextcloud-mariadb and nextcloud-mariadb-root. The MariaDB database
reads only its own two, so it can run without Nextcloud, and the admin
Secret matches the default keys of a vault copy.

An upgrade keeps every password: the Secrets are seeded from the former
nextcloud-credentials. MariaDB refuses a change of
rootPasswordSecretKeyRef, so a release from 0.5 or older keeps its root
password in nextcloud-credentials; helm detects that from the live
MariaDB object, Argo CD needs database.legacyRootSecret=true.

The dead smtp.host value is removed. With the generator, each Secret
has its own ExternalSecret and Password generator.

Tested as a tenant on berry-compute: 0.5.0 upgraded to this version
with unchanged password hashes, database and admin login; a fresh
install with the generator wrote each Secret once.
