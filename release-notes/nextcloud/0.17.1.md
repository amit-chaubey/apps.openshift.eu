# nextcloud 0.17.1

Released 2026-11-03.

## Changes

### Webmail login with the platform's client

With `sso.enabled` the webmail login (`mailRoute.sso`) uses the client from Secret
`nextcloud-sso` as well, which now also carries `sso-issuer-url`. The login pod waits for
that Secret and reads it at start.

## Upgrade

Nothing to do. Nextcloud and the Mailu front restart once, as on every chart version.
