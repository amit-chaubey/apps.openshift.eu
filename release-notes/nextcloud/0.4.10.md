# nextcloud 0.4.10

Released 2026-10-21.

## Changes

### nextcloud 0.4.10 runs Nextcloud 33.0.10 ([#27](https://github.com/hoolia/apps.openshift.eu/pull/27))

Nextcloud 33.0.8-apache is a frozen tag and never receives the PHP
fix for CVE-2026-109618 and CVE-2026-109619 (php2shell). Move to the
maintained 33.0.10-apache tag, built on PHP 8.4.27 or later.
