# nextcloud 0.4.8

Released 2026-10-11.

## Changes

### Let the gate pass on a clean clone

The check job failed on main: helm could not build the dependencies
of mailu and nextcloud, because it builds only from repositories
added by name, and the lock file of nextcloud named mailu 0.1.0 while
Chart.yaml asks for 0.1.4. The gate now adds the repositories a chart
names, and the lock file matches Chart.yaml again.

### Bundle the labelled mailu in nextcloud

mailu 0.1.5 carries the app labels on its objects. nextcloud still
bundled 0.1.4, so the mail server inside a nextcloud release stayed
unlabelled. The render with the new dependency differs from the old
one in labels and annotations only.
