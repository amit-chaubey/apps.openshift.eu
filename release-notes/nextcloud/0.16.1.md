# nextcloud 0.16.1

Released 2026-10-31.

## Changes

### Fetching mail from another mailbox

With `mailu.upstream.fetchmail.enabled` Mailu fetches mail from an outside account into
a mailbox (Mailu admin, Fetched accounts). The fetchmail pod now runs on the node of the
other Mailu pods (mailu 0.2.2).

## Upgrade

Nothing to do. The Nextcloud pod restarts once for the new chart version.
