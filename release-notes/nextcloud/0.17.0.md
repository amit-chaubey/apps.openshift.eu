# nextcloud 0.17.0

Released 2026-11-03.

## Changes

### Single sign-on from the platform

`sso.enabled` labels the Route with `sso.routeLabels`. A platform that watches the labels
creates the OpenID Connect client and writes Secret `nextcloud-sso` into the namespace;
within a minute Nextcloud sets up its provider from that Secret, and removes it again when
the Secret or the value goes. No client id or secret in the values.

### Setup changes apply without a restart

The cron container runs the setup again within a minute when the values change it, for
example a new `oidc` block. Before, such a change waited for the next restart.

## Upgrade

Nothing to do. Nextcloud and the Mailu front restart once, as on every chart version.
