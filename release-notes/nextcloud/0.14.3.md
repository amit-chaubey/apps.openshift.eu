# nextcloud 0.14.3

## Changes

### ONLYOFFICE edits OpenDocument, RTF, TXT and CSV files

The setup sets the editable formats of the ONLYOFFICE connector from the new value
`onlyoffice.editFormats`, by default `odt`, `ods`, `odp`, `rtf`, `txt` and `csv`. The
connector opened them read-only before, because its own default lists only the Office
Open XML formats. Saving such a file may lose formatting that the format cannot hold.

`doc`, `xls` and `ppt` cannot be edited in place: the editor converts them to a `docx`,
`xlsx` or `pptx` copy.

## Upgrade

No values change. Nextcloud restarts once.
