# nextcloud 0.4.5

Released 2026-10-08.

## Changes

### Let cert-manager make the DKIM key of the mail server

The platform publishes the DKIM record from the Secret that holds the
key. The DNSEndpoint no longer asks for an MX record: the platform's
DNS provider cannot write one. TXT values carry their quotes, the form
in which the provider stores them.
