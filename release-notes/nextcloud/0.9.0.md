# nextcloud 0.9.0

Released 2026-10-26.

## Changes

### Nextcloud 35.0.2

The chart runs Nextcloud 35.0.2 (image `35.0.2-apache`, pinned by
digest), the latest stable release. A new install starts on 35.

### Data volumes survive deleting the Application

As in 0.8.1: the installation, user-file and mail volumes carry
`argocd.argoproj.io/sync-options: Delete=false,Prune=false`, so a
cascading delete of the Application keeps the customer's data.

## Upgrade

Nextcloud upgrades one major version at a time: an instance must run
chart 0.8.0 or 0.8.1 (Nextcloud 34) before it takes this release. An instance
still on Nextcloud 33 does not start on 0.9.0; the image refuses the
jump and leaves the data untouched, so install 0.8.1 first.

The first start after the upgrade runs the database migration
(`occ upgrade`) with Nextcloud in maintenance mode, and the
once-per-version setup step updates the store apps. Take a backup
first.
