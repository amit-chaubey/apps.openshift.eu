# nextcloud 0.4.1

Released 2026-10-05.

## Changes

### Keep the nextcloud setup script from blocking the start

On one upgrade the script waited forever for an exclusive lock on
config.php that nothing visible held, the startup probe killed the
container, and Nextcloud stayed down. Version 0.4.1 runs every step
under a timeout and a total budget and skips what fails, tests the
lock before the first write and gives the file a new inode when it
cannot be locked, and starts cron only once Nextcloud serves.
