# nextcloud 0.16.2

Released 2026-10-31.

## Changes

### Mailu admin menu entries under /mail

The Mailu admin menu entries that navigate by script (Antispam) and the table language
files now carry the `/mail` prefix. Before, Antispam opened a Nextcloud "Page not found".

The Mailu front pod restarts on every chart version, so a changed prefix configuration is
always loaded.

## Upgrade

Nothing to do. The Nextcloud and Mailu front pods restart once for the new chart version.
