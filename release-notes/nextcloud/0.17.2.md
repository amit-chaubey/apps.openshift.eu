# nextcloud 0.17.2

Released 2026-11-04.

## Changes

### The single sign-on request moves from the Route to the Deployment

`sso.routeLabels` is gone. The platform's label goes on Deployment `nextcloud`, through
`nextcloud.deploymentLabels`; `sso.enabled` still makes Nextcloud and webmail use Secret
`nextcloud-sso`.

## Upgrade

Move the label from `sso.routeLabels` to `nextcloud.deploymentLabels`. Nextcloud and the
Mailu front restart once, as on every chart version.
