# nextcloud 0.18.1

Released 2026-11-15.

## Changes

### Longer tolerance for storage stalls

The Nextcloud liveness probe allows 30 consecutive failures at 10-second intervals, five
minutes, before it restarts the container. The readiness probe still takes Nextcloud out of
the Service during a storage stall, without a restart that cannot repair storage.

## Upgrade

The upgrade restarts Nextcloud and the Mailu frontend. Nothing else to do.
