# nextcloud 0.19.2

Released 2026-11-16.

## Changes

### Missing database indices at every start

With `settings.repairOnUpgrade` on, the setup script runs `occ db:add-missing-indices`,
`db:add-missing-columns` and `db:add-missing-primary-keys` at every start of Nextcloud. An
app update (Mail) adds optional indices without a new Nextcloud version, and the steps ran
only once per Nextcloud version, so those indices stayed missing and setup checks warned.
On an instance without missing indices the three steps take about 2 seconds.

Store app updates and the expensive repair steps still run once per Nextcloud version.

## Upgrade

No action. The Nextcloud and Mailu front pods restart once for the `chart-version` pod
annotations; at that start the missing indices are added.
