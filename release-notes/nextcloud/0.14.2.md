# nextcloud 0.14.2

## Changes

### Background jobs use the public address

The setup sets `overwrite.cli.url` to the public address (`https://<host>`) at every
start. It used to stay at the value from the first install, `https://localhost`. Every
`occ` command and background job built its links with it, and Talk's signaling server
refused their calls with `403 Authentication check failed`, because it accepts only the
configured Nextcloud address. Deleting a user with `occ user:delete` failed on that, and
room changes made by background jobs never reached the signaling server.

## Upgrade

No values change. Nextcloud restarts once.
