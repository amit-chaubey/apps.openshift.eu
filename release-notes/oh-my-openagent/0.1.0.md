# oh-my-openagent 0.1.0

Released 2026-11-15.

## Changes

### First release

Runs OmO Native (npm package `omo-ai`, 5.1.70) in a browser terminal behind an OpenShift
login:

- One pod with the terminal (ttyd and tmux), the OpenShift `oauth-proxy` and, with
  `gateway.upstream`, a token proxy that sends the pod's ServiceAccount token to an
  OpenAI-compatible gateway. No model key is stored.
- The image holds node 24, ttyd, tmux, git, ripgrep and fd. It holds no OmO: the pod
  installs `omo.package@omo.version` from `omo.registry` into the home volume on first
  start.
- The home directory is a volume, kept when the release is removed.
- `builds.enabled` builds the terminal image in the project; `terminal.image` uses a
  prebuilt one.
