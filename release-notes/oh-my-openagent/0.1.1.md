# oh-my-openagent 0.1.1

Released 2026-11-15.

## Changes

### OmO keeps its MCP catalog cache after a restart

OmO creates its MCP identity key `~/.omo/agent/config-identity.key` with mode 0600 and
ignores a key with any other mode. On each mount of the home volume the kubelet's fsGroup
ownership change made the key group-writable, so after the first restart OmO printed
"wrong mode; persistent catalog cache is disabled" and kept no MCP catalog cache.

The container now sets the key back to 0600 on every start, before OmO runs. It creates
no key; OmO still writes it on first use.

## Upgrade

Nothing to do. The pod restarts once, because the start script changes. The terminal
image is unchanged.
