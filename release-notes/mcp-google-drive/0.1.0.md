# mcp-google-drive 0.1.0

Released 2026-10-26.

## Changes

### Google Drive for your agents, with each user's own login

The chart adds Google's hosted Google Drive MCP server to the project as a
RemoteMCPServer. Each user authorizes it with their own account in the agent UI;
the agent then reads with that user's rights. Users grant read-only scopes unless
`write` is true.

### Selectable by bundle, server and category

The RemoteMCPServer is an add-on labelled `mcp.openshift.eu/server: google-drive`,
`mcp.openshift.eu/bundle: google-workspace` and `mcp.openshift.eu/category: productivity`.
An agent gets it when it lists the bundle or the server name, for example
`mcps.bundles: [google-workspace]` in the openhands chart 0.10.0 or later.

## Upgrade
