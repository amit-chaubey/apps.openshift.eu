# openwebui 0.2.4

Released 2026-10-25.

## Changes

### The agent's own token for MCP servers

The token proxy can carry the instance's own OpenID Connect token on MCP calls.
With tokenProxy.agentToken.tokenUrl set, calls under tokenProxy.agentToken.paths
(default /mcp) get a token from a client_credentials grant at that
endpoint, authenticated with a short-lived ServiceAccount token for
tokenProxy.agentToken.audience (federated client authentication). No
secret is stored; the token is kept until shortly before it expires.
Model calls keep the ServiceAccount token. serviceAccount.labels puts
labels on the ServiceAccount, for example the one a platform uses to
register it as a client of the realm.

## Upgrade

Nothing changes until tokenProxy.agentToken.tokenUrl is set. The pod
restarts once, because the token proxy script changed.
