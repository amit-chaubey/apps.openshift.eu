# openwebui 0.4.0

Released 2026-10-25.

## Changes

### Tools for every user

`openwebui.memberTools` lets users, not only admins, write their own tools
and connect tool servers from their browser. A tool is Python that runs in
the pod with the pod's permissions, so turn it on only for people you trust
with that. Off by default.

### Document vectors in Qdrant

`qdrant.url` stores the vectors of uploaded documents in a Qdrant instead of
the built-in store on the data volume. Chart `qdrant` requires an API key:
set `qdrant.apiKeySecret.name` to its Secret `<release>-qdrant-api-key`.
Vectors of documents uploaded before the switch stay in the built-in store
and are no longer searched; upload those documents again.

### Faster document indexing

The local embedding model encodes 64 chunks per call instead of one.

## Upgrade

Nothing to do. The openwebui pod restarts once for the new embedding batch
size.
