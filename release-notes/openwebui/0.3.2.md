# openwebui 0.3.2

Released 2026-10-25.

## Changes

### Room for an agent at work

The openwebui container now requests 100m CPU and 2Gi and is limited to 4 CPU and 16Gi, so a
busy agent is neither killed for memory nor throttled hard. The sizes
follow measured usage of the agents on the platform with generous
headroom. The proxy sidecars may use 256Mi instead of 128Mi.
