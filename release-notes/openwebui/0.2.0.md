# openwebui 0.2.0

Released 2026-10-21.

## Changes

### openwebui 0.2.0 with MCP tools, terminal and Jupyter ([#29](https://github.com/hoolia/apps.openshift.eu/pull/29))

mcp.enabled offers the gateway's MCP endpoints (the namespace's team
endpoint and public) as tool servers to every user, through the token
proxy that adds the instance's ServiceAccount token. workbench runs Open
Terminal and a Jupyter server as sidecars on 127.0.0.1 from an image
that holds the CLIs, with HOME on the data volume, as the terminal and
the code execution engine.

Open WebUI reads its terminal connection once at startup and found the
terminal sidecar not yet listening. The workbench containers now run as
native sidecars (init containers with restartPolicy Always), which are
started and ready before the main containers.
