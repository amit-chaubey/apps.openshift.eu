# openwebui 0.2.2

Released 2026-10-22.

## Changes

### Bind login groups to a ClusterRole

Kubernetes refuses a Role that grants permissions the creator does not
hold. A project admin, and the project's Argo CD with admin, do not hold
the verb login, so the group lockdown of 0.1.2, 0.3.5 and 0.2.1 failed
to sync for them ("attempting to grant RBAC permissions not currently
held"). oauth.loginClusterRole names a ClusterRole holding that verb;
allowedGroups are bound to it in a RoleBinding <name>-app-login, which
needs only bind on that ClusterRole. roleRef is immutable, hence the new
binding name. Empty keeps the chart's own Role for cluster admins.
