# openwebui 0.2.3

Released 2026-10-24.

## Changes

### Logins without an owner

Without an owner the chart passed an empty email domain, which
oauth-proxy reads as a domain no address matches, so a group or
project-editor instance let nobody in. It now passes --email-domain=*
and the SubjectAccessReview decides who logs in. Owner instances render
the same object.
