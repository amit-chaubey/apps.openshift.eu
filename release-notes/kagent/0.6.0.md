# kagent 0.6.0

Released 2026-11-16.

## Changes

### Declarative agents and model configs from values

`agents` renders Declarative Agents in the release namespace and `modelConfigs` their
ModelConfigs, with the model API key from the tenant vault (`apiKey.vaultItem`, Secret
`model-<name>`) or from an existing Secret.

An agent with `a2a.enabled` is published on the A2A gateway named by
`a2a.gatewayNamespace`: the chart labels its Service for the gateway's route policy and
adds a ReferenceGrant, the gateway's upstream bearer Secret and a NetworkPolicy that
admits port 8080 from the gateway namespace only. `a2a.callers` lists callers outside the
cluster in the Service annotation `a2a.callersAnnotation`.

## Upgrade

Nothing to do. With `agents` and `modelConfigs` empty the chart renders what 0.5.6
rendered.
