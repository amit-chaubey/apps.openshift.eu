# kagent 0.3.0

Released 2026-10-24.

## Changes

### Roles a tenant can grant

Upstream's writer and getter Roles use wildcard rules that a project
admin cannot grant, so a tenant's Argo CD could not sync the chart. The
chart now renders them with explicit rules; the platform grants the
full set.

### Static MCP servers

remoteMCPServers defines the tenant's own RemoteMCPServers, with
credentials from the tenant vault.

### Example tool server

examples.enabled adds the tool server of the upstream example agents,
bound to view in the release namespace only.
