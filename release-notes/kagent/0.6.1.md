# kagent 0.6.1

Released 2026-11-17.

## Changes

### Example agents on a tool server elsewhere

The upstream example agents call RemoteMCPServer `kagent-tool-server`. A
`remoteMCPServers` entry of that name now satisfies them instead of `examples.enabled`:
the agents use the tool server the entry points at, for example the team's own
`kagent-tools`, and the chart runs no example tool server of its own. The chart refuses
the entry together with `examples.enabled`, because both make `kagent-tool-server`.

## Upgrade

Nothing to do. Values that rendered with 0.6.0 render the same.
