# kagent 0.1.0

Released 2026-10-24.

## Changes

### kagent 0.1.0: tenant controller and UI behind the OpenShift login ([#41](https://github.com/hoolia/apps.openshift.eu/pull/41))

The tenant part of kagent: upstream controller and UI with namespaced
RBAC, behind the OpenShift login (oauth-proxy, ServiceAccount as OAuth
client). kmcp, kagent-tools and the built-in agents are off; the
platform kagent-operator provides the CRDs and the access to team
namespaces. NetworkPolicies keep the upstream UI Route without answer.

The chart refuses to render without upstream.rbac.namespaces, because
empty renders cluster-wide RBAC. ci/check.sh reads charts/<n>/ci/
test-values.yaml, as chart-testing does, and lints in namespace test.

login.provider oidc uses the upstream oauth2-proxy and trusted-proxy
mode, which gives each person their own sessions; the OpenShift login
issues no JWT, so it runs the controller unsecure with one shared user.
The chart refuses mismatched combinations. With upstream kmcp enabled
it adds kmcp's leader-election Role.
