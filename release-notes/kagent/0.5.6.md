# kagent 0.5.6

Released 2026-11-15.

## Changes

### Example tool server on kagent-tools 0.3.1

With `examples.enabled`, the tool server `kagent-tool-server` runs kagent-tools 0.3.1
instead of 0.1.3. 0.1.3 answered an MCP client's reply to a server request with an empty
`200` and no content type, which an MCP gateway (agentgateway 1.6) turns into a `500`; MCP
clients then dropped the session. 0.3.1 answers `202`, as the MCP specification requires.
Command, flags and tool names are unchanged.

## Upgrade

Nothing to do. With `examples.enabled` the tool server pod restarts once.
