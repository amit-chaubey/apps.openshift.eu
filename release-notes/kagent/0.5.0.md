# kagent 0.5.0

Released 2026-10-25.

## Changes

### The login client as part of the release

With login.oidc.keycloakClient.create the chart writes the login client
as an EDP KeycloakClient in the release namespace: clientId
login.oidc.clientId, redirect https://<route.host>/oauth2/callback, and
the client secret of the Secret the login proxy reads, so the secret
stays in the tenant vault. It needs the EDP Keycloak operator and a
realm the namespace may use; on a shared realm a tenant's clientId
starts with <tenant>-. Off by default.
