# kagent 0.5.3

Released 2026-11-04.

## Changes

### Login for accounts named by an email address

With `login.provider: openshift`, an account named by an email address got
`403 Invalid Account` although it had access to the project. The login proxy now passes
every account to its access review, which decides who enters.

## Upgrade

Nothing to do. The login proxy pod restarts once.
