# kagent 0.4.0

## Changes

### kagent 0.4.0: upstream kagent 0.10.4 and a tenant login boundary

The chart runs upstream kagent 0.10.4 with oauth2-proxy 7.15.5, and the
upstream Route straight to the UI is off. With login.provider oidc the
chart sets the scope, the Secret kagent-oidc and a login skip list of
the login page and static assets only; upstream also skipped the
substrate harness gateway with any suffix. Pods of every namespace that
networkPolicy.agentNamespaceSelector selects reach the controller, so
ServiceAccounts of the tenant use it like its people do. The README
states who gets in. The platform's kagent CRDs must be 0.10.4 first.
