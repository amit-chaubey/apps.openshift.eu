# kagent 0.2.0

Released 2026-10-24.

## Changes

### kagent 0.2.0 on CloudNativePG with OIDC login ([#43](https://github.com/hoolia/apps.openshift.eu/pull/43))

The controller's database is now a CloudNativePG Cluster in the
release namespace instead of upstream's development PostgreSQL; the
controller reads the URL from the generated app Secret. With
login.provider oidc an ExternalSecret writes the oauth2-proxy Secret
from the tenant's secret store, and oauth2-proxy runs under the
project UID. NetworkPolicies admit the CloudNativePG operator and the
HTTP-01 solver, which the default deny blocked.

The controller trusts the identity its callers send, so the team
namespaces reach port 8083 from kagent-managed pods only.
