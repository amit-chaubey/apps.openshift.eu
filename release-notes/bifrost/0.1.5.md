# bifrost 0.1.5

Released 2026-11-04.

## Changes

### Gateway image v1.5.16

Image v1.5.8 answers 401 to every virtual key, so a gateway installed with the chart default
could not serve a request with a key. The default is now v1.5.16.

## Upgrade

The gateway pod restarts once for the new image. An instance that sets
`upstream.image.tag` keeps its own image.
