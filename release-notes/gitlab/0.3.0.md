# gitlab 0.3.0

Released when merged. Contains 0.2.0, which was never published.

## Changes

### Taking over a running GitLab

New values to install the chart over a GitLab that runs already, without
recreating a bucket, the database or a volume:

- objectStorage.create=false: no bucket claim and no conversion Job; the
  existing buckets are named per object type in objectStorage.buckets
- postgres.spec: merged over the database Cluster spec (WAL volume, backup
  plugin, affinity, parameters)
- route.enabled=false: no Route, for GitLab behind another ingress
- dataAnnotations: annotations on GitLab, the database Cluster, the cache
  volume and the bucket claim

postgres.resources may now be null: the Cluster then sets no resources.
Defaults are unchanged: an upgrade renders the same objects as 0.2.0.
