# gitlab 0.2.0

Released when merged.

## Changes

### GitLab API exporter

With apiExporter.enabled the chart runs gitlab-api-exporter next to GitLab: a
small Deployment that reads the GitLab API with a Reporter read_api access
token and serves Prometheus metrics, with a PodMonitor:

- gitlab_merges: every merge of the last apiExporter.mergeDays days, with
  author, merger and self_merged ("false" when someone else merged)
- protection of the default branch and the protected branches
- the latest default branch pipeline and the failed runs of each schedule
- open merge requests with both AI review verdicts and no confidence-gate
  status for over 2 hours

The token is the new key api-exporter-token of gitlab-credentials, from
secrets.apiExporterToken or the vault item secrets.externalSecret.apiExporterItem.
Off by default: an upgrade changes nothing until it is switched on.
