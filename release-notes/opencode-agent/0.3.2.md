# opencode-agent 0.3.2

Released 2026-10-21.

## Changes

### opencode-agent 0.3.2 turns opencode's provider off ([#25](https://github.com/hoolia/apps.openshift.eu/pull/25))

OpenCode enables opencode.ai's public inference with the key "public" on
every agent, so a prompt could leave through it instead of the gateway.
opencode.disabledProviders (default [opencode]) writes disabled_providers
into the generated opencode.json. A user's own global config outranks it,
so an allow policy there turns the provider back on.
