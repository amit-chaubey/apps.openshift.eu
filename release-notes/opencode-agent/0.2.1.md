# opencode-agent 0.2.1

Released 2026-10-20.

## Changes

### Add MCP runtimes and more CLIs to opencode-agent ([#14](https://github.com/hoolia/apps.openshift.eu/pull/14))

Chart 0.2.1. The OpenCode image can run project-defined local MCP
servers (node, npm, npx, uv, uvx) and carries go, terraform, packer,
ansible-core with common collections, hf, fastapi, uvicorn, gh,
promtool, gitleaks, rclone, kubectl-mariadb, kubectl-mdba and database
clients. The A2A adapter keeps its SQLite task store in an emptyDir:
during a rolling update two adapters on one shared file failed with
"locking protocol" and the new pod never became ready.
