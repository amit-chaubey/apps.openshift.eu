# opencode-agent 0.9.0

Released 2026-11-15.

## Changes

### Plugins switched on by name

`opencode.pluginOptions` lists names from `opencode.pluginCatalog`, a map of a name to one
pinned npm version. Each name adds its version to the plugins of `opencode.json`, after
`opencode.plugins` and once. An order form can offer the catalog as checkboxes: the chosen
names go into `pluginOptions`, and only the chart decides which package and version a name
installs.

The chart's catalog:

| Name | Package | Licence |
|---|---|---|
| `opencode-dynamic-context-pruning` | `@tarquinen/opencode-dcp@3.2.0` | AGPL-3.0-or-later |
| `opencode-handoff` | `opencode-handoff@0.7.0` | MIT |

Values can add entries. A name that is not in the catalog, or an entry without one exact
version, fails the render instead of installing whatever is latest.

## Upgrade

Nothing to do: `pluginOptions` is empty by default and the plugins stay `opencode.plugins`.
OpenCode 2.1.1 installs a plugin from a scope registry (`opencode.npmScopes`) only when the
default registry is that registry too: set `opencode.env.NPM_CONFIG_REGISTRY` to it.
