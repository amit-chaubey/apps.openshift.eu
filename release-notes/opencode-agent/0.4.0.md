# opencode-agent 0.4.0

Released 2026-10-24.

## Changes

### Admit the tenant's callers by JWT

kagent forwards the Authorization header of whoever chats with an agent
to the agent's A2A adapter. The adapter knew only the per-agent static
credential, so kagent's chat got 401 from every opencode agent. With
a2a.tenantAuth (on by default) the adapter also admits a bearer JWT of
the agent's tenant: a ServiceAccount token from a namespace <tenant> or
<tenant>-*, or an OIDC token from one of a2a.tenantAuth.oidcIssuers
whose groups claim holds <tenant> or <tenant>-*. The static credential
keeps working, so agent-to-agent calls are unchanged.

The adapter default moves to opencode-a2a 2.0.0+hoolia.2, the first
release with this support. A prebuilt a2a.image must be that release or
later, or a2a.tenantAuth.enabled set to false.
