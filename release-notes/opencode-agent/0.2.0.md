# opencode-agent 0.2.0

Released 2026-10-20.

## Changes

### Add toolset and A2A peers to opencode-agent ([#12](https://github.com/hoolia/apps.openshift.eu/pull/12))

Chart 0.2.0. The OpenCode image now carries a command-line toolset at
the newest upstream releases (oc, kubectl, helm, argocd, virtctl, odf
and more); the build runs every tool once as a non-root user and
fails when one does not start. a2a.peers renders A2A_PEERS for the
model plugin's a2a_list_agents and a2a_call tools, and the agent
instructions describe those tools only when they exist; they no
longer point the model at a tool that is not registered.
