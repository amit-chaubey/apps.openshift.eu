# opencode-agent 0.1.1

Released 2026-10-19.

## Changes

### Show the work tree in the project picker ([#10](https://github.com/hoolia/apps.openshift.eu/pull/10))

The OpenCode web UI keeps its open projects in the browser, so a new
browser starts with none and New session does nothing. Add project
offers a picker rooted at HOME, which was /workspace/.home and did not
contain the work tree, so the repository could not be picked.

HOME is now /workspace, the parent of the work tree. The XDG
directories stay under /workspace/.home, so sessions and settings are
kept. Release 0.1.1.
