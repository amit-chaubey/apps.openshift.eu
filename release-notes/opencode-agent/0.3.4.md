# opencode-agent 0.3.4

Released 2026-10-22.

## Changes

### opencode-agent 0.3.4 turns on formatter and todo ([#32](https://github.com/hoolia/apps.openshift.eu/pull/32))

The generated opencode.json uses the OpenCode 2 keys: update disable
replaces autoupdate, formatter formats edited files, experimental.todo
gives the agent a visible to-do list, worktree.directory keeps worktrees
on the volume and watcher.ignore skips dependency and build trees. The
opencode container gets no probe: the new pod waits for the old pod's
workspace lock and kagent's Deployment rolls.
