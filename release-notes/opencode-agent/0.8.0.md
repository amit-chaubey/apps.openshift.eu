# opencode-agent 0.8.0

Released 2026-10-29.

## Changes

### MCP servers outside the gateway with the agent's own token

An `mcp.servers` entry with `url` and `agentToken: true` is called through the token proxy
with the agent's own token from `tokenProxy.agentToken`, as `path` entries on the gateway
already are. Use it for an MCP server that accepts tokens of that realm itself, such as a
server behind oauth2-proxy next to its app. The chart registers the URL as the proxy target
`<namespace>.<name>` (`/_target/<namespace>.<name>`), and the proxy sends the token to that
URL only. The URL is https, or plain http to a Service of the cluster.

## Upgrade

Nothing to do. To move a server from `opencode.config.mcp` to the agent token, remove it
there and add `{name, url, agentToken: true}` under `mcp.servers`.
