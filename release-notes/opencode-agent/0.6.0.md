# opencode-agent 0.6.0

Released 2026-10-26.

## Changes

### Google Workspace, Microsoft 365 and Azure CLIs in the image

The OpenCode image the chart builds now carries `gws` (Google Workspace CLI
0.22.5), `m365` (CLI for Microsoft 365 11.11.0) and `az` (Azure CLI 2.91.0),
next to `aws` (AWS CLI v2) that it already had. The three are pinned to these
releases; the `gws` download is checked against its published digest. The build
runs each of them once and fails when one does not start.

The image holds no credential for them. Log in from the agent's terminal:
`gws auth login`, `m365 setup` once and then `m365 login`, `aws configure sso`,
`az login --use-device-code`. The login stays in the home directory on the
agent's volume, and the agent then acts with your rights in that service.

The image grows by about 700 MB, mostly the Azure CLI and the CLI for
Microsoft 365.

## Upgrade

Nothing to do. With `builds.enabled` the upgrade starts a new image build, and
the agent restarts on the new image when it is done. With `builds.enabled`
false, the image in `opencode.image` decides which tools the agent has.
