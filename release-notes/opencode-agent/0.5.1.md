# opencode-agent 0.5.1

Released 2026-10-25.

## Changes

### Token proxy: agent identity through the tenant realm

The token proxy copy follows images/agent-identity/token-proxy.py. With
AGENT_TOKEN_VIA_URL set, the agent first gets a token from its tenant's own
realm with its ServiceAccount token, and that token is the client assertion
for the shared realm. Without the variable nothing changes.
