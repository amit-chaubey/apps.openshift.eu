Released 2026-10-27.

## Changes

### The token proxy can forward to registered MCP servers

The chart's copy of the token proxy gains `TARGETS_FILE`: requests under
`/_target/<id>` go with the agent token to the URL the file names. This chart
sets no `TARGETS_FILE`, so its agents behave as before.
