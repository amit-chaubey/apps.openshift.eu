# opencode-agent 0.3.3

Released 2026-10-21.

## Changes

### opencode-agent 0.3.3 sends no body on 204 and 304 ([#26](https://github.com/hoolia/apps.openshift.eu/pull/26))

The UI and token proxies framed every response without a length as
chunked, including 204 and 304, and wrote the closing chunk after
them. Those responses have no body, so oauth-proxy read the stray
chunk as the start of the next response and failed that request:
the web UI showed no providers. Responses without a body now go out
without chunked framing.

openwebui carries the same token proxy as opencode-agent and CI
requires the copies to match. A regression test covers 204 and 304
on a reused connection.
