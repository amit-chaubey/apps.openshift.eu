# opencode-agent 0.4.2

Released 2026-10-25.

## Changes

### Labels on the Agent

agentLabels puts labels on the kagent Agent. kagent creates the agent's
ServiceAccount itself, so a platform that registers ServiceAccounts as
OpenID Connect clients reads its label from the Agent instead; with
tokenProxy.agentToken the agent then carries its own token on MCP calls.

## Upgrade

Nothing changes until agentLabels is set.
