# opencode-agent 0.3.0

Released 2026-10-20.

## Changes

### Run opencode-agent on OpenCode 2 ([#19](https://github.com/hoolia/apps.openshift.eu/pull/19))

OpenCode 2.1.1 replaces `opencode web` with `opencode serve` and
accepts HTTP Basic only for the user "opencode". oauth-proxy sends
the person as the Basic user, so a new ui-proxy container hands the
UI to OpenCode with OpenCode's own credential; it keeps the Host
header for terminals and tunnels WebSocket upgrades.

The A2A adapter comes from the hoolia/opencode-a2a fork with the
OpenCode 2 API, built from its source archive. OpenCode 2 migrates
opencode.db in place, so backup-db.sh keeps one copy of the 1.x
store under the work tree lock before the first 2.x start.

setup-helm "latest" falls back to Helm 3.18.4 when its release lookup
fails, and Helm 3 words the schema error differently, so the access
mode test failed now and then. Helm is pinned and the test accepts
both wordings.

semgrep 1.182.0 has no musl wheel; uv built its sdist, which lacks
semgrep-core, so every new OpenCode image build failed its tool check.
