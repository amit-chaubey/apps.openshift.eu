# opencode-agent 0.7.0

Released 2026-10-28.

## Changes

### Remote MCP servers as values, with the agent's own credential

The new value `mcp.servers` writes remote MCP servers into `opencode.json`: `path` on
`gateway.upstream` through the token proxy, or `url` as is. The new value
`vaultSecrets` reads properties of a vault item through an `ExternalSecret` into a
Secret `<person.name>-agent-<name>`, mounted read-only into the opencode container as
files. An `mcp.servers` entry with `auth` sends a header built from those files
(`basic`, `bearer` or `raw`); before OpenCode starts the header is written to a file in
memory, and `opencode.json` refers to it as `{file:...}`, so the credential is in no
ConfigMap, pod spec or command line.

## Upgrade

Nothing to do. Remote MCP servers in `opencode.config.mcp` keep working and win over
`mcp.servers` entries of the same name; move them to `mcp.servers` to give them a
credential. The agent pod restarts once, since the opencode command changed.
