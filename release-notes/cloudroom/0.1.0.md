# cloudroom 0.1.0

Released 2026-11-15.

## Changes

### First release

Cloudroom core 0.1.111 as one pod with its HTTP API behind a Route, for the Cloudroom
desktop app's "Connect your own Core". Claude Code 2.1.325 and OpenCode 1.18.34 are in the
image, built in the project; Codex 0.155.1 is an option. With `gateway.upstream`, Claude
Code and OpenCode use the model gateway through a token proxy and no model key is stored.
Workspaces, logins and history live on one volume.

## Upgrade

New chart; nothing to upgrade.
