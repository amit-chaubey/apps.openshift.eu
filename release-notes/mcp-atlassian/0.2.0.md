# mcp-atlassian 0.2.0

Released 2026-10-27.

## Changes

### The chart is renamed from atlassian-mcp

MCP server charts are named `mcp-<server>`. This chart continues `atlassian-mcp`
0.1.0, whose release stays available; new versions come under this name only.
The selector label `app.kubernetes.io/name` is now `mcp-atlassian`.

### Optional token check in front of the server

`auth.enabled` (default `false`) puts an oauth2-proxy sidecar (v7.15.5, the
shared library chart `mcp-auth`) in front of the server. It takes the Service
port, and the server listens on localhost only. A request needs a bearer JWT of
`auth.issuerUrl` for one of `auth.audiences` (default: the release namespace),
else 401; with `auth.allowedGroups` a token of another group gets 403. The
caller's `Authorization` header reaches the server unchanged, streams pass as
they come, and `/.well-known/oauth-protected-resource` names the issuer without
a token, so an agent can find out that its own token fits. Without
`auth.issuerUrl` every request but the health paths gets 401.

The token check takes the `Authorization` header that `credentials.mode:
perCaller` reads the Atlassian account from, so it works with
`credentials.mode: shared` only; the chart refuses the other combination.

## Upgrade

A release of `atlassian-mcp` cannot be upgraded to this chart: its selector
label changes. Uninstall the `atlassian-mcp` release and install
`mcp-atlassian` with the same values; the server keeps no data.
