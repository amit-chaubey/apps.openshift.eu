# mcp-atlassian 0.3.0

Released 2026-10-28.

## Changes

### Per caller with a shared fallback

`credentials.callerOverride: true` in shared mode lets a caller that sends its own
Atlassian account act as itself; callers without one keep acting as the shared account.
The Service then carries `agentgateway.dev/mcp-credential-header`, so a gateway hands the
caller's header to the server as its `Authorization`. An invalid caller account is
refused, not replaced by the shared one.

### Bearer tokens through the cloud ID

`credentials.cloudId` sends Bearer tokens (OAuth access tokens, API keys of Atlassian
service accounts) to `api.atlassian.com/ex/<product>/<cloudId>`, while Basic accounts keep
using the site URL. In shared mode the shared account must then be
`ATLASSIAN_OAUTH_ACCESS_TOKEN` in `credentials.existingSecret`.

## Upgrade

Nothing to do: both values are off by default.
