# mcp-slack 0.1.0

Released 2026-10-26.

## Changes

### New chart: the Slack MCP server for a project's agents

Runs korotovsky slack-mcp-server 1.3.0 with the Bot User OAuth Token of a Slack app in
your workspace. Agents read the channels the bot is invited to, their threads, the users
and the user groups, without a Slack login of their own. The server serves streamable HTTP
at `/mcp` behind an MCP gateway and admits only the own project and the namespaces you
list.

### No tool writes to Slack by default

Posting messages (`slack.addMessage`, optionally limited to `slack.addMessageChannels`)
and reactions (`slack.reactions`) are switches, each with its own bot scope. Message
search needs a user token and is not available with a bot token.
