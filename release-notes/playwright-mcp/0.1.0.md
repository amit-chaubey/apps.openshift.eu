# playwright-mcp 0.1.0

Released 2026-10-20.

## Changes

### Add chart playwright-mcp ([#13](https://github.com/hoolia/apps.openshift.eu/pull/13))

One Playwright MCP server per team: headless Chromium behind a
streamable HTTP MCP endpoint that an agentgateway selector discovers
through the Service appProtocol, an in-memory profile per session,
and a NetworkPolicy that admits the project and listed namespaces and
lets the browser reach the public internet only.
