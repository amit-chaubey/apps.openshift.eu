# mcp-server 0.2.0

Released 2026-10-20.

## Changes

### Let mcp-server sit next to its app ([#18](https://github.com/hoolia/apps.openshift.eu/pull/18))

mcp-server 0.2.0 can put kube-rbac-proxy in front of the server, so
every call needs a ServiceAccount token allowed services/proxy on the
Service, publish it by a reencrypt Route for an MCP gateway on another
cluster, and map single Secret keys to environment variables.
