# mcp-server 0.1.0

Released 2026-10-20.

## Changes

### Add chart mcp-server ([#16](https://github.com/hoolia/apps.openshift.eu/pull/16))

One MCP server from any streamable HTTP image per release, its
credential from an existing Secret, a Service an agentgateway selector
discovers through appProtocol, and a NetworkPolicy that admits the
project and listed namespaces and limits egress to the public internet
plus named private upstreams.
