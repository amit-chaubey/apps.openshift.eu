# openhands 0.2.0

Released 2026-10-23.

## Changes

### openhands 0.2.0 discovers RemoteMCPServers ([#37](https://github.com/hoolia/apps.openshift.eu/pull/37))

Sidecar mcp-sync turns every kagent RemoteMCPServer of the project
into an MCP server of the agent and keeps the list in step: gateway
URLs go through the token proxy, servers that need Secret headers are
skipped, entries a user made are left alone. It also writes the git
token as GITLAB_TOKEN into the secrets store, which is what turns on
the UI's git provider features.

The ClusterRole that reads RemoteMCPServers belongs to kagent, which
owns the CRD; the chart only binds it (mcpDiscovery.clusterRole,
default kagent-remotemcpserver-view) in its own namespace.
