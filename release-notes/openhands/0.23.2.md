# openhands 0.23.2

Released 2026-11-17.

## Changes

### Token limits are written on every start that needs them

The token proxy is now the first container of the pod. The kubelet starts the next container
only after the `postStart` hook of the one before has returned, and the hook of
`agent-canvas` reads the gateway's model list through the token proxy. With the proxy after
`agent-canvas` that list was never there on a pod start: `llm.contextShare` found no context
windows, and with an earlier profile-defaults marker present no `max_input_tokens` was
written. A new gateway model got no profile either.

The hook also tries the model list for up to a minute. Without the list it writes no profile
defaults and no marker, so the next start writes them.

## Upgrade

No values change. The agent image is rebuilt once under the tag `1.38.0-0.23.2` and the agent
pod restarts. On that start a profile whose limit was never written by the chart gets its
`max_input_tokens`. `oc exec` and `oc logs` without `-c` still open `agent-canvas`
(annotation `kubectl.kubernetes.io/default-container`).
