# openhands 0.15.0

Released 2026-10-28.

## Changes

### Agents bring their own credential to a shared MCP server

The new value `vaultSecrets` reads properties of a vault item through an
`ExternalSecret` into a Secret `<release>-<name>`, mounted read-only as files, never
as environment. An `mcp.servers` entry may now be `{name, auth}`: `mcp-sync` builds one
request header from those files (`basic`, `bearer` or `raw`) and stores it as the
secret of that MCP server's entry, shown redacted in **Settings > MCP**. Behind the
gateway, use a header such as `X-Atlassian-Authorization` that the server's Service
names in `agentgateway.dev/mcp-credential-header`; the token proxy replaces only
`Authorization`. A rotated vault item reaches the agent without a restart.

### Servers by URL

An `mcp.servers` entry `{name, url}` adds an MCP server that has no `RemoteMCPServer`.

## Upgrade

Nothing to do: `mcp.servers` entries that are names work as before. With
`build.enabled` the upgrade builds a new image, whose tag carries the chart version, and
the pod moves to it when the build is Complete. An MCP server entry you added by hand in the
UI to hold the same credential (for example a local `uvx mcp-atlassian`) can be removed
once the discovered entry carries the credential.
