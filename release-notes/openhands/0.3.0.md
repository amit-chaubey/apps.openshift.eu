# openhands 0.3.0

Released 2026-10-24.

## Changes

### openhands 0.3.0: Agent Canvas 1.33.0, OAuth MCP redirect to the route ([#38](https://github.com/hoolia/apps.openshift.eu/pull/38))

Agent Canvas 1.33.0 ships agent-server 1.58.1 and automation 1.25.1.
The settings, MCP, secrets and agent-profile endpoints the seed and
mcp-sync scripts call are unchanged, and the entrypoint still carries
the two STATIC_SERVER_BIND_HOST lines the build rewrites to loopback,
so the Containerfile and scripts need no change.

The upstream entrypoint now defaults LOG_LEVEL to WARNING, which only
quiets the backends' startup output.

OpenHands registers http://localhost:<random port>/callback as the
OAuth redirect of an MCP server added in the UI, which the browser of
a hosted agent never reaches, so no OAuth MCP could be installed.
With route.host set, module mcp_oauth_redirect (loaded by the
agent-server like canvas_ui_tool) registers
https://<route.host>/mcp-oauth/callback instead and listens on a
fixed loopback port that the static server routes to, behind the
OpenShift login. One OAuth login runs at a time.

mcp-sync also gives discovered servers an icon: annotation
openhands.dev/icon on the RemoteMCPServer, else the logo of a known
name such as gitlab or grafana.
