# openhands 0.6.1

Released 2026-10-25.

## Changes

### Icons on installed MCP servers

Agent Canvas 1.33 draws a logo on an installed MCP server only when its
URL equals an entry of the Library, and drops the icon of the server's
settings. Servers behind the token proxy never match, so every card
showed the generic symbol. The image build now patches the frontend to
keep the icon and show it when no Library entry matches; the build
fails when the frontend no longer has the expected shape.

Icons come from the RemoteMCPServer annotation openhands.dev/icon, from
a list of known names (now with kagent-tools, librenms, memory, netbox,
kubernetes, bitwarden and others, and a working netbox logo), from the
new icon field of mcpServers, and the Kubernetes logo for the built-in
kubernetes server.

## Upgrade

A new image builds on the next sync; an instance with build.enabled
false keeps its image.
