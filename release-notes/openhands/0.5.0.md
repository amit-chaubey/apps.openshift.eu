# openhands 0.5.0

Released 2026-10-24.

## Changes

### A2A server, one agent per conversation

A new sidecar makes the agent an A2A server, so other agents and kagent
can chat with it. Every A2A context becomes its own conversation, and
every titled conversation started in the UI is also a sub-agent named
<release>/<title> at /agents/<slug>/, which continues that conversation.
Calls need a bearer token of the tenant (ServiceAccount or OIDC with the
tenant in its groups claim) or the optional static credential.

### Listed in kagent

With kagent installed the chart registers a BYO Agent named like the
release. kagent runs it as a small relay pod in front of the sidecar,
because the agent-server listens on loopback only. Set
a2a.tenantAuth.oidcIssuers to the realm kagent logs users in with, or
kagent's chats get 401.
