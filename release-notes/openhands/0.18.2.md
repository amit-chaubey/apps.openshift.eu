# openhands 0.18.2

Released 2026-11-04.

## Changes

### MCP streams stay open while idle

The token proxy no longer closes an event stream (`text/event-stream`) that stays silent for
10 minutes. MCP clients keep a stream open for messages from the server, and Firecrawl,
Playwright and most other servers send nothing on it, so the proxy cut it after 600 seconds
and the client logged `McpError: Connection closed`. Event streams now have no read timeout
and use TCP keepalive; other requests keep the 600 second timeout. The error line names the
method and path of the failed request.

### Kubernetes MCP server starts in every conversation

With `kubernetesMcpServer.enabled`, the stdio server `kubernetes` reads the pod's
ServiceAccount from a kubeconfig file in the scripts ConfigMap (`--kubeconfig`), instead of
the `KUBERNETES_SERVICE_HOST` and `KUBERNETES_SERVICE_PORT` values in its `env`. OpenHands
stores that `env` as secrets, and a conversation started without them failed with
`no current-context is set and no contexts are defined in kubeconfig`.

## Upgrade

Nothing to do. The agent pod restarts once, because the token proxy code changes.
