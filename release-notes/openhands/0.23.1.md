# openhands 0.23.1

Released 2026-11-17.

## Changes

### Only models with a large window get a token limit

`llm.minInputTokens` is 400000 by default instead of 150000. OpenHands counts every MCP
tool definition in full against `max_input_tokens`, also the tools the gateway defers:
285 tools measured 254k tokens, the system prompt another 4k. With 0.23.0 a model with a
262144-token window got a limit of 157000, below the tool definitions alone, and its
conversations would have been condensed on every step.

With the new default only models with a window of at least 667k tokens get a limit: a 1M
window gives 600000, which leaves about 340k for the history. Every other model condenses on
`condenser.maxSize` only, as before 0.23.0. An instance with fewer MCP tools can lower
`llm.minInputTokens`.

## Upgrade

Use this release instead of 0.23.0. An instance that ran 0.23.0 keeps the limits it wrote on
its 262144-token profiles: remove them under **Settings > LLM** (clear **Max input tokens**).
The agent image is rebuilt once under the tag `1.38.0-0.23.1` and the agent pod restarts.
