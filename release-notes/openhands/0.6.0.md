# openhands 0.6.0

Released 2026-10-24.

## Changes

### The gateway is a provider under Settings > LLM

Agent Canvas 1.33 lists models as profiles of a provider connection. The
chart only wrote the plain model settings, so Settings > LLM showed no
provider. With gateway.upstream set, the seed now creates the provider
connection llm.connection.name (default Gateway) to the token proxy, one
profile per model in llm.model and llm.models, and activates the profile
of llm.model. The profile default that earlier versions left without a
connection is removed.

### SHELL and the rest of the opencode-agent toolset

The image sets SHELL=/bin/bash, which Claude Code needs for its Bash
tool. The build adds ripgrep, xxd, vi, lsof, psmisc, procps, iproute2,
ping, traceroute, whois, bc, dos2unix, gnupg, sysstat, cpio and file
from Debian, and ruff from PyPI, so the image carries what the
opencode-agent image has. opencode itself stays out: its build is for
musl.

## Upgrade

A new image builds on the next sync. The pod restarts because the seeded
values change, and the seed adds the connection and profiles to the
existing settings. An instance with build.enabled false keeps its image:
point image.tag at a 0.6.0 build to get the tools.
