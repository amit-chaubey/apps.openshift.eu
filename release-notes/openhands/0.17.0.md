# openhands 0.17.0

Released 2026-10-30.

## Changes

### The condenser no longer loops on many MCP tools

`condenser.maxTokens` now defaults to `0`: the history is condensed by event count
(`maxSize`) and the model's own input limit only. OpenHands counts the history tokens
itself and includes every MCP tool definition, also the tools the gateway defers and the
model never receives. With a few hundred MCP tools that overhead alone passed the former
default of 120000 tokens, so the condenser ran before every model call, forgot one event
each time and never let the agent answer.

## Upgrade

Nothing to do. The pod writes the new condenser setting into the settings and every
OpenHands agent profile at its next start. A conversation started before keeps the
condenser it was started with: start a new conversation.
