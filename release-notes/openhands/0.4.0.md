# openhands 0.4.0

Released 2026-10-24.

## Changes

### openhands 0.4.0 publishes UI MCP servers to the team ([#42](https://github.com/hoolia/apps.openshift.eu/pull/42))

A remote MCP server a user adds in the OpenHands UI now becomes an
AgentgatewayBackend of the project, with the headers OpenHands would
send in a Secret owned by the backend. The platform turns it into a
gateway endpoint and a RemoteMCPServer, so every agent of the team
discovers it; removing it in the UI removes the backend. OAuth,
in-pod and local servers stay personal, and the platform's admission
policy decides which hosts a project may reach. The UI entry's
description shows the outcome.
