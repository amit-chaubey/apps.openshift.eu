# openhands 0.16.0

Released 2026-10-28.

## Changes

### git authenticates to GitHub without configuration

`github.com` now always has a git credential helper, also when `git.providers` names no
GitHub host. It answers with the first token it finds: the environment variables
`GITHUB_TOKEN`, `GH_TOKEN` and `GITHUB_PERSONAL_ACCESS_TOKEN`, then the secrets
`GITHUB_TOKEN` and `GITHUB_PERSONAL_ACCESS_TOKEN` in the agent-server secrets store
(**Settings > Secrets**). A GitHub token added in the UI, or exported in the agent's
shell, works for `git clone`, `fetch` and `push` at once, so the agent no longer writes
its own `~/.gitconfig`.

### Token names from the environment

A `git.providers[].secretName` may now list several names separated by spaces;
`env:<VAR>` reads an environment variable of the agent, any other name a stored secret.
The `git.host` token is sent through the same helper.

## Upgrade

Nothing to do. A `git.providers` entry for `github.com` keeps its own `secretName`.
With `build.enabled` the upgrade builds a new image, whose tag carries the chart version,
and the pod moves to it when the build is Complete. A credential helper the agent wrote
into `~/.gitconfig` by itself still works next to the new one and can be removed.
