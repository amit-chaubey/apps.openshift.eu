# openhands 0.1.1

Released 2026-10-22.

## Changes

### openhands 0.1.1 preconfigures agents

The first-run wizard asked for an LLM and overwrote the seeded model with
openai/gpt-5.6-sol; the image now marks it done in the page (the
frontend's only condition is localStorage openhands-onboarded).

agentSecrets seeds the environment of the ACP agents into the
agent-server secrets store, so Claude Code and Codex no longer ask for
keys and base URLs; agentProfiles seeds selectable ACP agent profiles.

Verified on berry-ai (sam-10x): fresh browser opens without wizard;
Claude Code answers through /anthropic on the gateway; Codex answers
with a provider config that turns off its WebSocket transport.
