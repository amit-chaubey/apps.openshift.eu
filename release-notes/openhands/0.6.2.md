# openhands 0.6.2

Released 2026-10-25.

## Changes

### Documents and diagrams

The image gains a toolset for architecture work: LibreOffice without GUI
(soffice: Word, PowerPoint, Excel, Visio import, PDF export), pandoc,
graphviz, plantuml with nwdiag network diagrams, rsvg-convert,
ImageMagick and mermaid-cli (mmdc, on the image's Chromium), plus
markitdown, python-docx, docxtpl, python-pptx, openpyxl, vsdx and
diagrams from PyPI. The build renders a Word file to PDF and a Mermaid,
an nwdiag and a diagrams picture to prove they work.

soffice is a wrapper that puts LibreOffice's program directory first in
LD_LIBRARY_PATH: the base image's LD_LIBRARY_PATH otherwise resolves the
UNO libraries outside their $ORIGIN runpath and LibreOffice does not
start.

### Skill marketplaces

skills.marketplaces registers skill marketplaces in Claude Code or
OpenHands plugin format, for example github:<owner>/<repo>.

### No leftover profile default

The seed moves agent profiles that still use the LLM profile default to
the active profile before it removes default; 0.6.0 and 0.6.1 left it in
place because the delete was refused while the agent profile default
used it.

### Wispr Flow icon

The wispr-flow MCP server shows its logo.

## Upgrade

A new image builds on the next sync. The image is larger by about
600 MB (LibreOffice and fonts).
