# openhands 0.9.0

Released 2026-10-25.

## Changes

### Every gateway model under Settings > LLM

`llm.gatewayModels` (default `true`) adds a profile for every model the gateway
lists at `/v1/models`, on every pod start. Profiles that exist, also those a user
edited, are left as they are; the active profile does not change. Before, only
`llm.model` and `llm.models` were offered. Set it to `false` to keep that list.
