# openhands 0.9.4

Released 2026-10-25.

## Changes

### MCP servers of every Project the agent may see

MCP discovery lists the OpenShift Projects the agent's ServiceAccount may see
and the RemoteMCPServers in each, besides its own namespace. A namespace that
refuses the list is skipped, so Kubernetes RBAC on the namespace decides which
servers an agent sees: a platform that grants an agent read access to
RemoteMCPServers and get on the namespace in another namespace makes that
namespace's servers appear. A name that also exists in the own namespace becomes
<namespace>-<name>. Without such grants only the own namespace is discovered, as
before.
