# openhands 0.9.5

Released 2026-10-26.

## Changes

### Claude Code conversations survive a restart

Claude Code keeps its session store in `~/.claude`, which was not on the data
volume. After every pod restart it could not resume an open conversation and
started a fresh session with only a replay of the history. The chart now mounts
`~/.claude` from the data volume (subdirectory `claude`), next to settings and
`~/workspace`. Sessions started before the upgrade are not recovered; new ones
persist. The upgrade restarts the pod once.
