# openhands 0.18.0

Released 2026-10-30.

## Changes

### LLM profile defaults

The new value `llm.profileDefaults` holds OpenHands LLM settings for every profile on the
gateway connection, in the agent-server's field names. Default: `stream: true`,
`enable_encrypted_reasoning: false`, `inline_image_urls: true`. They are written into each
new profile, and into existing profiles once per value, so an edit in **Settings > LLM**
stays until the value changes.

### Condenser token limit comes from the model

`condenser.maxTokens` is removed. The condenser condenses by event count (`maxSize`) and by
the model's own `max_input_tokens`, set per model in **Settings > LLM** or for every
profile in `llm.profileDefaults`. OpenHands counts every MCP tool definition into that
total, also the tools the gateway defers: with a few hundred MCP tools a limit of 120000
condensed before every model call, and the agent never answered.

## Upgrade

Remove `condenser.maxTokens` from your values; a value still passed is ignored. The pod
writes the profile defaults into existing profiles at its next start. A conversation
started before keeps the condenser and model settings it was started with: start a new
conversation.
