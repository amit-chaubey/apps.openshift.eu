# openhands 0.9.1

Released 2026-10-25.

## Fixes

### Claude Code ends its session after the first turn

Through a gateway that streams no token usage (an OpenAI-compatible backend
behind an Anthropic-format endpoint), the Claude ACP adapter failed with
"Cannot read properties of undefined (reading 'input_tokens')" and every
later message answered "The Claude Agent session has ended". The image build
patches the adapter so missing usage counts as zero.

## Upgrade

The image is rebuilt on upgrade.
