# openhands 0.12.0

Released 2026-10-27.

## Changes

### Long conversations are condensed

The OpenHands agent summarizes its history once it holds more than 120 events or
120,000 tokens, down to about half, with the agent's own model; the first 4 events
stay. Before, only 240 events triggered it: gateway models have no token limit
LiteLLM knows, so a conversation could send several hundred thousand tokens per
step. The new values `condenser.enabled`, `condenser.maxSize`,
`condenser.maxTokens` and `condenser.keepFirst` are written into the settings and
every OpenHands agent profile at the next start, and again only when they change;
a condenser edited in the UI stays until then. Claude Code and other ACP agents
compact their own history and are not affected.

### The most capable gateway model is the default

With `llm.model` empty, the first model of `llm.preferredModels` (default
`claude-opus-5-5`, `claude-fable-5-1`, `claude-opus-5`, `claude-sonnet-5`, `claude-sonnet-4-6`) that
the gateway lists becomes the default model. A release that sets `llm.model`
keeps it. Every gateway model stays selectable as a profile from the model menu
under the chat input.

### MCP server icons show after an upgrade

The patched frontend bundles, and every bundle and page that names one of them,
get new file names in the image build. A browser that cached the upstream
bundles under their old names, which the server marks immutable, now loads the
patched ones, so installed MCP servers show their icons.

## Upgrade

The image is rebuilt and the agent pod restarts once. The condenser settings
replace the ones in the UI once. With `llm.model` empty and a gateway, the model
of `llm.preferredModels` becomes the active profile once. Nothing else to do.
