# mcp-nextcloud 0.1.0

Released 2026-10-27.

## Changes

### Nextcloud MCP server for the agents of a project

Runs cbcoutinho nextcloud-mcp-server 0.201.2 with the bearer passthrough patch
(`ghcr.io/hoolia/nextcloud-mcp-server:0.201.2-bearer.2`, by digest):
files, notes, calendar, contacts, deck, tables and talk of one Nextcloud as the
calling account. The server passes each caller's bearer token to Nextcloud,
which checks it; a call without one gets 401. Objects are named
`mcp-nextcloud`, so they never collide with Nextcloud's own.
