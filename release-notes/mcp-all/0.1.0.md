# mcp-all 0.1.0

Released 2026-10-26.

## Changes

### Every MCP bundle as a switch

The chart holds mcp-bundle-google-workspace and mcp-bundle-microsoft-365 0.1.0
as switches (`googleWorkspace.enabled`, `microsoft365.enabled`), so one values
file picks bundles and, with `<server>.enabled: false`, single servers. Nothing
is installed until a bundle is switched on.
