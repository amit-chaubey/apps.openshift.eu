# omniroute 0.3.1

Released 2026-10-04.

## Changes

### Fix the manual release gate and omniroute upgrades

ci/release.sh piped the check into tail without pipefail, so a failed
check did not stop a release, and it skipped the secret scan when
gitleaks was missing. It also indexed a freshly built package when the
release already existed: the index digest of omniroute 0.2.0 did not
match the released file. The script now stops on a failed check,
requires gitleaks and a clean tree, and rebuilds the index from the
packages of all releases.

omniroute 0.3.1 replaces the pod instead of rolling it: the data
volume is ReadWriteOnce, so a new pod on another node could never
start. The README says when generated secrets are not kept.
