# omniroute 0.3.0

Released 2026-10-04.

## Changes

### Run omniroute from the upstream image

Building from source in a tenant project took an hour and about 8Gi of
memory: npm ci and the Next.js build both stalled under the default
2Gi limit and were still slow at 8Gi. Upstream publishes the image, so
the chart pulls it by default. build.enabled keeps the source build
for those who need it.

ci/release.sh releases a chart by hand while the release workflow
cannot run.
