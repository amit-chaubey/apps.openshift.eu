# mcp-bundle-google-workspace 0.1.0

Released 2026-10-26.

## Changes

### Google Workspace for your agents in one release

The chart installs the Gmail, Google Drive, Google Docs, Google Sheets and
Google Calendar MCP servers (charts mcp-gmail, mcp-google-drive,
mcp-google-docs, mcp-google-sheets, mcp-google-calendar 0.1.0) with one shared
OAuth client. Each user authorizes every server with their own Google account in
the agent UI; scopes are read-only unless a server's `write` is true. An agent
gets the servers when it lists `mcp.bundles: [google-workspace]` (openhands
0.10.0 or later).

## Upgrade

Nothing to do: first release. Create the OAuth client as the chart's Delivery
instructions describe.
