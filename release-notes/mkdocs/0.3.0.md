# mkdocs 0.3.0

Released 2026-10-10.

## Changes

### mkdocs 0.3.0: build on a push through a webhook

source.webhook adds the GitLab, GitHub and Generic webhook triggers to
the BuildConfig, the Secret that is part of the webhook address, and the
RoleBinding that lets the Git server call the webhook without a login.
An image trigger restarts the site after the build, so the poller is not
needed: set source.pollSchedule to empty. The default stays polling.
