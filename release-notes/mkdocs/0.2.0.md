# mkdocs 0.2.0

Released 2026-10-09.

## Changes

### mkdocs: optional OIDC login and source credentials

### mkdocs: rebuild when the source branch moves

### mkdocs: describe the chart, add a test site

### mkdocs: refuse requests that bypass the login proxy

A NetworkPolicy cannot close the site port where another policy of the cluster opens it. With login on, nginx now serves only the proxy in its own pod; probes use /healthz.

### mkdocs 0.1.1: accept a cookie secret of any length

A secret generated outside the chart can be longer than the 16, 24 or 32 bytes oauth2-proxy accepts; the schema refused it and the render failed. Such a value is now hashed to 32 characters.

### mkdocs 0.2.0: roll out without an image trigger

The image trigger rewrites the image field of the Deployment and a GitOps tool reverts it, so an Application without an ignore rule never became Synced. The Deployment now names the fixed tag in the cluster registry, and the poller job waits for the build and restarts the pods for the new image.
