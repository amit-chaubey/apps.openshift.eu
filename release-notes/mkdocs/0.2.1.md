# mkdocs 0.2.1

Released 2026-10-09.

## Changes

### mkdocs 0.2.1: exact refs, no password in a timeout, one build per commit

The poller matched any ref ending in the name and took the tag object of an annotated tag, so such a ref was rebuilt on every poll. A timeout of git ls-remote raised with the URL, password included, in the message. A build now names its commit, so a build that fails before the clone is not repeated. A ref such as 1.0 stays a string.
