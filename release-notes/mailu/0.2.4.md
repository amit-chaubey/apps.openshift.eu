# mailu 0.2.4

Released 2026-11-01.

## Changes

### Icons and arrows in the topology view

Each Mailu Deployment shows its product icon in the topology view of the OpenShift console (nginx for the front, Roundcube for webmail, Dovecot, Rspamd, Tika, Mailu for the rest), and an arrow to each component it depends on: the front to admin, webmail, postfix and dovecot, postfix to admin, rspamd and dovecot, and so on. The Redis StatefulSet shows the Redis icon.

## Upgrade

Nothing to do. Only workload metadata changes; no pod restarts.
