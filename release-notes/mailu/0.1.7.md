# mailu 0.1.7

Released 2026-10-25.

## Changes

### Alert rules can be left out of monitoring

`monitoring.enabled` made the ServiceMonitors and the PrometheusRule
together. A platform that evaluates alerts centrally scrapes the
metrics of the project but keeps the rules in one place: a rule in the
project then fires twice or nowhere.

The new value `monitoring.alerts` (default `true`) switches the
PrometheusRule on and off. With `monitoring.enabled=true` and
`monitoring.alerts=false` the chart makes the metrics Services, the
ServiceMonitors and the NetworkPolicy for the scraper, and no rules.
The default renders the same objects as 0.1.6.

### imapsync pinned to 2.326

The imapsync image was `latest` with `pullPolicy: Always`, against the
rule that a chart pins every image. It is now tag `2.326` with
`IfNotPresent`. The image is the same build as `latest` on the day of
this release. Only a release with `imapsync.enabled=true` changes.
