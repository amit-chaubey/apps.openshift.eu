# mailu 0.1.1

Released 2026-10-07.

## Changes

### Add nextcloud chart

Nextcloud on the upstream chart with a MariaDB custom resource and an
OnlyOffice document server, as a tenant installs it: no SCC binding,
the containers that need root ask for UID 0, OnlyOffice without the
MKNOD capability, secrets generated once, own Ingress for both
hostnames. Depends on the mailu chart, on by default.

Talk, the whiteboard, notify-push, the task worker, monitoring and
backup of the private chart are not part of this first version.
