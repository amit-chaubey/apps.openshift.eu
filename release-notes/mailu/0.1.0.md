# mailu 0.1.0

Released 2026-10-04.

## Changes

### Add mailu chart

Mailu as a tenant installs it: the upstream chart 2.6.3 with the
components that need root asking for UID 0, a Route for the web
interface, own mail Service with annotations from values, secrets
generated once. The mail Service is cluster-internal by default; a
public address is a value. ci/check.sh builds chart dependencies.
