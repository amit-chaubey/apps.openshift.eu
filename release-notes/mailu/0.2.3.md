# mailu 0.2.3

Released 2026-10-31.

## Changes

### Front Dovecot ipc service runs without chroot

The front's Dovecot `ipc` service gets `chroot =`, like the login services and `anvil`.
The pod has no `SYS_CHROOT` capability, so the first IMAP proxy session started `ipc`,
which failed with `chroot(/run/dovecot/empty) failed: Operation not permitted` and was
retried every minute. Proxied logins kept working.

## Upgrade

Nothing to do. The front pod restarts once for the new configuration.
