# mailu 0.2.6

Released 2026-11-15.

## Changes

### Refused mail domains

New value `refusedDomainPattern`: a regular expression (RE2, case-insensitive). When
`upstream.domain` matches it, the render stops with the message "mail domain ... is not
allowed here: give a domain you own". An installation uses it to keep its own zones out of
customer mail domains. Example: `(^|\.)example\.net$` refuses `example.net` and every name
below it.

The default is empty: every domain is accepted, as in 0.2.5.

## Upgrade

No action. The chart renders the same objects as 0.2.5.
