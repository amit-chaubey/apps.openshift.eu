# mailu 0.2.2

Released 2026-10-31.

## Changes

### Fetchmail runs next to the other Mailu pods

`upstream.fetchmail` gets the settings of the other components: it runs as root and
follows the admin pod onto its node, because it mounts the same ReadWriteOnce mail
volume. Before, a switched-on fetchmail pod could land on another node and stay in
`ContainerCreating` with a Multi-Attach error. Fetchmail stays off by default.

## Upgrade

Nothing to do. Installs without fetchmail render the same objects.
