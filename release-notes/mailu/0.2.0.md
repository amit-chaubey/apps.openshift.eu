# mailu 0.2.0

Released 2026-10-27.

## Changes

### Postfix and rspamd survive a short storage stall

On network storage (CephFS) a metadata failover freezes file access for about a
minute. The probes of postfix and rspamd timed out after 1 second, three times
in a row, and the container was restarted in the middle of the stall. Their
probes now wait 10 seconds per check, and the liveness probe restarts the
container after 10 failures, about 100 seconds, instead of 3.

### Postfix starts after it was killed on network storage

The start script of the postfix image removes `/queue/pid/master.pid` only if
it can lock the file. On network storage the lock of a killed postfix can stay
behind; the script then kept the file, `postfix start-fg` reported "already
running" and exited, and the container restarted for hours. An init container
now changes the start script to remove the file unconditionally. The pod runs
one postfix (`strategy: Recreate`), so no running postfix owns the file at
that moment.

### MX record with the other DNS records

With `dns.enabled` the DNSEndpoint now also requests
`MX <domain> 10 <first of upstream.hostnames>`. Before, the MX record had to
be made by hand, and a domain without it received no mail. `dns.mx.enabled`
(default `true`) and `dns.mx.priority` (default `10`) control it. A DNS
provider that does not write MX records from a DNSEndpoint skips it.

### Outgoing address with its own name

`egressService`, the second public address that postfix sends from, never
shares its address with other Services of the project any more, and it now
uses `externalTrafficPolicy: Local`. With `dns.enabled` it gets the hostname
`egressService.hostname` (default `outbound.<domain>`) as an A record, a
platform that writes reverse DNS from that name gives the address a matching
PTR record, and the SPF record names it as `a:<hostname>`. Receiving servers
then find a sender whose address, reverse name and SPF agree.

The outgoing address cannot be the address of the mail Service: that Service
keeps the clients' addresses (`externalTrafficPolicy: Local`), and MetalLB
shares such an address only between Services that select the same pods.

## Upgrade

The postfix and rspamd pods restart once. Mail in the queue stays on the
volume.

A release with `dns.enabled` gets its MX record. If you made one by hand at a
DNS provider that external-dns serves, check with `dig MX <domain>` that one
record remains, or set `dns.mx.enabled: false`.

A release with `egressService.enabled` and `global.publicAddress.shared`
gets a new outgoing address. Update a PTR record or SPF entry you set by hand.
