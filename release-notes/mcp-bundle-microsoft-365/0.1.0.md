# mcp-bundle-microsoft-365 0.1.0

Released 2026-10-26.

## Changes

### Microsoft 365 for your agents in one release

The chart installs the Microsoft 365 MCP server (chart mcp-microsoft-365 0.1.0).
Each user authorizes it with their own Microsoft account in the agent UI; only
tools that read are offered by default. An agent gets it when it lists
`mcp.bundles: [microsoft-365]` (openhands 0.10.0 or later).

## Upgrade

Nothing to do: first release. Register the Entra app as the Delivery
instructions of mcp-microsoft-365 describe.
