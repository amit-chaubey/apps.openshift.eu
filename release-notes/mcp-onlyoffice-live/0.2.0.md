# mcp-onlyoffice-live 0.2.0

Released 2026-11-02.

## Changes

### Formatting, tables and comment threads

Image `ghcr.io/hoolia/mcp-onlyoffice-live:0.2.0`. New tools: `format_text`, `insert_table`,
`edit_table`, `insert_list`, `insert_image`, `insert_chart`, `write_cells`, `format_cells`,
`comments`, `comment_reply`, `comment_resolve`, `comment_delete` and `run`, a script of the
ONLYOFFICE Office API for everything else. The value `scripts: false` removes `run`.

### Edits survive a close

`close` sends the pending edits first. A close straight after an edit lost them.

### Limits

Every editor call has a deadline, so a hung editor cannot hold a session. The browser of a
session reaches only the origins of its editor page.

## Upgrade

Nothing to do. The server restarts once and open live sessions end.
