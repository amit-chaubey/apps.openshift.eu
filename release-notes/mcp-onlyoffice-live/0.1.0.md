# mcp-onlyoffice-live 0.1.0

Released 2026-10-26.

## Changes

### First release: agents edit office documents live

The chart runs the MCP server `office-live` (image `ghcr.io/hoolia/mcp-onlyoffice-live:0.1.2`).
An agent opens a file from its own Nextcloud files in ONLYOFFICE and joins the co-editing
session; people in it see the agent's name, cursor and edits as they happen. Tools: `open`,
`create`, `read`, `insert` (also word by word), `replace`, `comment`, `track_changes`,
`save`, `view`, `close`, `sessions` and `file_status`.

The server forwards the caller's own `Authorization` to Nextcloud and holds no secret of
its own. It needs the ONLYOFFICE plugin `agent-bridge` in the Document Server, which the
`nextcloud` chart mounts.
