# atlassian-mcp 0.1.0

Released 2026-10-25.

## Changes

### First release

Jira and Confluence as an MCP server (sooperset/mcp-atlassian 0.23.1) for
a tenant or one of its teams (team puts it into <tenant>-<team>). By
default the server holds no account and every request carries its
caller's own Atlassian account; credentials.mode shared uses one account
from a Secret. The Service names the header an MCP gateway copies into
the backend Authorization (agentgateway.dev/mcp-credential-header), so a
caller can authenticate to the gateway and to Atlassian at once.
