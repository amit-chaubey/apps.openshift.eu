# mcp-microsoft-365 0.1.0

Released 2026-10-26.

## Changes

### Microsoft 365 for your agents, with each user's own login

The chart runs Softeria ms-365-mcp-server 0.172.0 in the project and adds it as
a RemoteMCPServer. Each user authorizes it with their own Microsoft account in
the agent UI; the agent then reads mail, calendar, files and, for work accounts,
Teams and SharePoint with that user's rights. Only tools that read are offered
unless `microsoft.readOnly` is false.

### Selectable by bundle, server and category

The RemoteMCPServer is an add-on labelled `mcp.openshift.eu/server: microsoft-365`,
`mcp.openshift.eu/bundle: microsoft-365` and `mcp.openshift.eu/category:
productivity`. An agent gets it when it lists the bundle or the server name, for
example `mcp.bundles: [microsoft-365]` in the openhands chart 0.10.0 or later.
