# mcp-auth 0.1.0

Released 2026-10-27.

## Changes

### Library chart with the token check of the MCP server charts

The token check that MCP server charts put in front of a server without
authentication of its own: an oauth2-proxy v7.15.5 sidecar, pinned by digest,
that accepts OpenID Connect bearer tokens of one issuer for an audience and a
group (401 without a valid token, 403 for another group), passes the caller's
`Authorization` header on, streams responses and serves protected resource
metadata (RFC 9728). A chart depends on it with `repository: file://../mcp-auth`;
it is never released on its own.
